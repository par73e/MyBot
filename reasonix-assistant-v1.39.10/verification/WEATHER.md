# Friday 天气工具与晨报

版本：`v1.39.10-assistant.8-weather-context`。工具、调度和数据源均由 Friday 云端宿主提供，无需额外 Skill。

## 使用方式

- 主动查询：向 Friday 询问“今晚会不会下雨”“现在空气质量如何”“明天学校天气怎样”。Agent 按问题选择地点、自然日、时段及数据类别。
- 手动晨报：说“按自动晨报的规则，现在播报一次”。Agent 先调用 `assistant_weather(action=morning_prompt)` 读取服务器当前共享的晨报正文规则，再根据个人上下文选址并调用 `view=briefing`，在当前对话直接回复。规则来自与定时晨报相同的常量，有摘要可核对，不需要粘贴长提示词；不创建、重跑或修改定时任务，不复用旧天气结果。自动任务保留通知 JSON 契约，手动调用返回普通中文正文。
- 晨间播报：每天在北京时间的起床时间生成全天简报，周一/三/四 10:00，周二/五 08:00，周六/日 11:00。天气平稳也正常播报。
- 宿主按所查日期提供默认地点候选：工作日学校，周末家；Agent在取数前结合当前／未来记忆及本次问题选择实际地点，晨报同样可以选择旅行目的地。候选与行程不代表实时GPS。

## 运行链路与提示词

`Heartbeat（每60秒、纯程序）→ 当日起床窗口 → 创建唯一日期任务 → 只读Agent读取默认候选与当前/未来记忆 → Agent决定地点 → assistant_weather(view=briefing，显式地点与选择依据) → 生成中文晨报 → 宿主验证取数凭证、通知结果及有效期 → 微信发送并写入当天会话`。

本轮选址与未来记忆变更详见 `WEATHER_CONTEXT.md`。普通查询的使用说明在 `internal/boot/prompt_policy.go`；工具参数/时间、单位及缺失值约束在 `internal/assistant/weather_query.go`。全天晨报完整提示词为 `internal/assistant/weather_morning.go` 的 `WeatherMorningInstructions`，只随晨报任务加入。宿主还附加现有通知 JSON 契约。长期记忆提供偏好及行程背景，不承担触发与去重职责。

晨报输出采用自然开头与固定分行结构：极端天气及有效预警优先放在第一段，随后依次为气温、降雨、湿度、风力，每项一个短段，段间空一行。每项默认只保留一组关键数据，只有重要异常才补充；降雨只选主要时段和变化，不罗列逐小时数值。全文通常约130至200字，不套用某天的数字或例句；正常空气质量与紫外线直接省略，明显异常才简短补充。不附加明日预报、出行/穿衣/健康建议或生活指数段落。语言平实、直接，以事实和准确动词表达，不使用比喻、拟人或刻意亲近的修辞。保留选址、完整取数、有效期及数据口径约束；调度和发送流程不变。这是源码提示词的调整，运行服务须更新程序后才会采用。

邮件和天气共用 Heartbeat，但使用独立任务与配置；暂停邮件不等于暂停晨报。天气起床时间目前保存在宿主 `assistant/weather.json` 的 `wake_times`，本版未新增 Agent 修改天气时间表的工具。

## 时效、故障与边界

- 一日起床后最多一小时补报；超过窗口不补发过时晨报。任务中途越过窗口也会在实际发送前拦截。
- 日期任务持久化去重；重启不会重发已完成晨报。分析失败最多三次、逐步退避；推送重试复用已生成结果，不重复分析。发送结果不确定时不盲目重发。
- 每次晨报必须真实调用本轮 `briefing` 查询，宿主核验任务/执行轮次绑定的取数凭证，不能仅凭模型声称取数成功。
- 各组件独立失败与缓存。实况10分钟、小时/逐日预报30分钟、当前AQI15分钟、预警/分钟降水5分钟。刷新失败时最多两小时旧数据仅供参考并标记陈旧；不能当作最新天气或“没有预警”。
- 今日是北京时间00:00–24:00，独立于微信会话06:00换日。小时预报不能补造已经过去的小时；逐日夜间区间可能延至次日早晨。
- 对比只在同坐标同口径预报间进行；昨天附近城市的历史再分析仅供背景，不当作精确同点实测温差。
- 同时兼容提供方带秒和仅精确到分钟的 ISO8601 时间。概率/湿度等0–1比例及风速m/s、能见度m均保留单位。
- 工具输出保持有效JSON并低于模型32KiB传输截断预算；过量组件明确标记 `output_limited`。缺数据、无覆盖、接口失败与无预警分开。
- 天气工具不接受任意URL、凭据路径或通知收件人。晨报进程仅暴露天气、记忆、待办和历史读取工具；数据中的文字不具有执行指令权限。

## 真实接口与私有配置

私有目录 `/var/lib/mybot/weather/qweather/` 保存凭据、Ed25519私钥和计划地点；目录0700、私有文件0600，均由mybot所有。具体家庭地址、坐标、私钥与令牌不进入源码快照。

原生Go实现固定Host与TLS校验、Ed25519短时JWT、不跟随重定向、每请求12秒超时、最多3并发。无需运行Python来取得天气。可查询：实况、逐日/逐小时预报、空气质量实况/小时及日预报、官方预警、分钟降水、生活指数、附近城市昨天历史再分析和日出日落。没有调用台风路径、太阳辐射或海洋产品。

真实服务器验收覆盖以上11类组件；晨报响应约28KiB，全部组件可用（鲜活或有效缓存）。逐小时天气与AQI均筛选到所需自然日，日预报和历史数据口径分别标注。真实结果仅在服务器私有目录保留；仓库证据只保存状态及字段结构。
