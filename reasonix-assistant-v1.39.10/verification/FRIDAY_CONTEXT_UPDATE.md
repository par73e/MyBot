# Friday 日常上下文调整

目标版本：v1.39.10-assistant.3，基于 assistant.2。

用户反馈：自我介绍仍提到部署工作区、已安装软件及代码任务，希望 Friday 关注本人和事务。

调整范围：

- 助手模式停止默认环境探测/环境说明及工作目录上下文；正常编程模式沿用原行为。
- 新回合防止重新加载部署字段；重开旧会话时按宿主来源和稳定消息 ID 移除模型侧历史环境字段，保持可见聊天记录、用户原文和个人状态。
- 常见个人助理工具直接展示，技术工具保持注册、原权限和按需调用入口。
- 提示词明确区分日常身份问题与用户明确提出的技术请求。

相关测试验证最终 provider 请求及旧会话恢复边界；真实模型验收脚本以旧版本创建隔离会话，再用新版本连续问候、自我介绍、能力说明及日常交流，同时验证记忆、待办和按需文件工具。

详细结果见 `friday-context-live.log` 及 `friday-context.json`。旧的 `friday-persona.json` 和原始交付包仍对应此前版本，不将其检查结果冒充本次版本的全量验收。
